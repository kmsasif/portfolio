## 💻 Local Preview

Simply double click `index.html` or run with any local development server:

```powershell
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```

Open `http://localhost:3000` in your browser.

---

## 🌐 Deploy to GitHub Pages

1. Commit and push your latest code to your repository:
   ```bash
   git add .
   git commit -m "Update portfolio with projects, resume details, and skills"
   git push -u origin main
   ```
2. In your GitHub repository at `https://github.com/kmsasif/portfolio`:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select branch `main` and folder `/ (root)`.
   - Click **Save**.
3. Your portfolio will be live at:
   `https://kmsasif.github.io/portfolio/`
